# La vie des plantes

Site vitrine e-commerce réalisé avec WordPress.

## Outils utilisés

- WordPress
- WooCommerce
- Elementor
- ShopLentor, anciennement WooLentor
- Contact Form 7
- Thème Flower Shop Lite

## Pages réalisées

- Accueil
- Boutique
- À propos
- Contact

## Importation dans Local

1. Compresser le contenu du dossier `site` au format ZIP.
2. Ouvrir Local.
3. Choisir l’option d’importation d’un site.
4. Sélectionner le fichier ZIP créé.

## Identifiants WordPress

- Identifiant : `admin`
- Mot de passe : `1234`
